# 一乐过滤 - 文档站

> 一乐过滤过滤器编辑文档站

## 项目简介

一乐过滤是一个高效、灵活的 POE 过滤器编辑与管理工具，同时支持 POE1 和 POE2。

主要特性：

- 🎮 POE1 & POE2 同步支持
- ✏️ 全量自定义可视化编辑，简单易上手
- 🔄 在线保存与更新，修改一次自动生效
- 💰 对接国际服市集物价，智能排序
- ☁️ 一键同步至官网云过滤，多设备无缝切换
- 🔗 过滤配置和音效包一键分享下载

## 本地开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm docs:dev

# 构建
pnpm docs:build

# 预览构建产物
pnpm docs:preview
```
