可以在这里分享和下载其他用户上传的音效包,可以上传自己制作的音效包给其他玩家使用

## 使用方法

在首页点击`基础功能-音效替换专区`,就可以看到所有用户上传的音效包链接了,可以直接下载,也可以自己 <mark>上传</mark> 自己的音效包,如图所示
