可以在这里分享和下载其他玩家自定义好的过滤文件

## 设置分享操作

在首页点击`我的-我的过滤`,即可看到自己的自定义过滤列表界面,点击`设置`按钮,可以设置分享状态,标签,过滤描述等信息,设置为分享后,你的自定义过滤就能在 <mark>分享过滤列表</mark> 中被其他用户看见和下载使用了,也可以生成分享链接直接分享给你的好友下载使用,如下图所示

![过滤分享下载1](/assets/other/过滤分享下载1.png)

![过滤分享下载2](/assets/other/过滤分享下载2.png)

::: tip 温馨提示
部分用户分享的过滤可能修改了默认的音效配置,请注意查看分享过滤的过滤描述,看看是否提供额外音效包下载
:::
