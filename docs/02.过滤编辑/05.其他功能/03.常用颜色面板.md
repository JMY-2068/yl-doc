常用颜色面板功能是将你常用的一些喜欢颜色,放到外观编辑的时的待选列表里,方便快速选择


## 使用方法

在首页点击`我的-颜色板管理`,就可以新增和管理你所有的常用颜色了,添加完后它们会显示在 <mark>常用颜色面板</mark> 中,如图所示
