## 1.显示和隐藏

- <TkIcon icon="ant-design:eye-filled" :size="24" style="vertical-align: -4px" /> 控制这个过滤块匹配的物品的显示和隐藏
- <TkIcon icon="pepicons-pop:music-note-single" :size="24" style="vertical-align: -4px" /> 控制这个过滤块匹配的物品自定义音效的开启和关闭
- <TkIcon icon="majesticons:sound-up" :size="24" style="vertical-align: -4px" /> 控制这个过滤块匹配的物品系统音效的开启和关闭

## 2.启用和禁用

<mark>启用</mark> 代表这个过滤块的规则会正常进行匹配

<mark>禁用</mark> 代表这个过滤块的规则会被跳过,继续往下匹配

以上面的图为例, 如果 我将 <mark>卡兰德的魔镜</mark> 禁用, 那么游戏里掉落 <mark>卡兰德的魔镜</mark> 的魔镜时,过滤不会匹配这个过滤块,也就是不会显示红底白字,会一直继续往下匹配到过滤最后面的 <mark>过滤该更新了</mark> 的过滤块


## 3.精确匹配和模糊匹配

<mark>精确匹配</mark> 指会严格匹配你所写的 <mark>基本类型</mark> ,也就是必须英文名完全相同
<mark>模糊匹配</mark> 指只要掉落的物品的英文名包含有你所写的 <mark>基本类型</mark> ,那么就会匹配这个过滤块
举个列子,真银药剂的英文的是 <mark>Silver Flask</mark> ,水银药剂的英文的是  <mark>Quicksilver Flask</mark>,假设存在以下方式的过滤文件

``` ts
Show # 药剂 - 药剂* - 真银药剂
    Identified False
    ItemLevel >= 85
    Rarity Normal Magic
    Class "Flasks" 
    BaseType "Silver Flask" // [!code warning]
    SetTextColor 255 255 255 
    SetBackgroundColor 0 0 0 
    SetBorderColor 136 136 255 199 
    SetFontSize 34
    DisableDropSound 

Show # 药剂 - 药剂* - 水银药剂
    Identified False
    ItemLevel >= 85
    Rarity Normal Magic
    Class "Flasks" 
    BaseType "Quicksilver Flask" // [!code warning]
    SetTextColor 255 255 255 
    SetBackgroundColor 0 0 0 
    SetBorderColor 136 136 255 199 
    SetFontSize 34
    DisableDropSound 
```

如果这个时候你想屏蔽 <mark>水银药剂</mark> ,正常做法是将 <mark>水银药剂</mark> 这个过滤块设置为 <mark>屏蔽</mark> ,但是因为模糊匹配的原因,真银药剂的英文名 <mark>Silver Flask</mark> 被水银药剂的英文名 <mark>Quicksilver Flask</mark> 包含,所以也会被匹配到,导致水银药剂还是会匹配到前面的真银药剂过滤块 ,进而还是显示

解决办法是将 <mark>模糊匹配</mark> 改为 <mark>精确匹配</mark> ,即添加 <mark>双等号</mark> 来表示精确匹配,这个时候真银药剂过滤块就只会匹配真银药剂了,水银药剂会正确匹配到水银药剂过滤块,从而被正确屏蔽掉


``` ts
Show # 药剂 - 药剂* - 真银药剂
    Identified False
    ItemLevel >= 85
    Rarity Normal Magic
    Class "Flasks" 
    BaseType == "Silver Flask" // [!code focus] [!code warning]
    SetTextColor 255 255 255 
    SetBackgroundColor 0 0 0 
    SetBorderColor 136 136 255 199 
    SetFontSize 34
    DisableDropSound 
```

## 4.修改外观

外观包含字体颜色,背景颜色,边框颜色三个颜色,可设置透明

::: tip 温馨提示
对于一些系统强制显示的物品,可以通过设置为 <mark>透明</mark> ,来隐藏物品的显示,可查看[屏蔽福袋](/edit/hide-bag)章节

外观支持提前预定义喜欢的颜色待选项,可查看[常用颜色面板](/edit/color-panel)章节

外观也支持整体复制色块和粘贴色块,方便批量快速修改,可查看[色块复制和粘贴](/edit/color-cv)章节
:::
