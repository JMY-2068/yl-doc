如果你想尝试着自己自定义过滤,并方便以后编辑的话,可以试着将过滤保存到云端

::: tip 温馨提示
保存到云端目前仅支持 <mark>POE 1</mark> ,POE2过滤修改请参考[本地导入和保存](/edit/localImportSave)章节
:::

## 功能介绍与优势

- 可以在多台设备上下载自定义好的过滤,无需每次去论坛下载初始的过滤
- 可以随作者过滤版本 <mark>自动更新</mark> ,无需每次都重新编辑,参考[过滤更新](/edit/updateFilter)章节
- 搭配[云过滤同步](/edit/cloud-sync)功能,实现每次修改过滤内容后无需重复下载即可生效的效果

## 如何操作

选择左侧预设过滤后,点击上方 <mark>保存到云端</mark> 按钮,即可,保存成功后会在自定义过滤列表中显示,如图所示
