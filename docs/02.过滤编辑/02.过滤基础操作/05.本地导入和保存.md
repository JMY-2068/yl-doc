本地导入和保底保存指的是导入你本地的 <mark>一乐过滤文件</mark> 直接编辑,可在保存完后直接覆盖本地过滤,适合临时性修改


## 和保存到云端的区别

- 本地导入的过滤无法保存至云端,如果你想要保留自己修改的内容,请使用[保存到云端](/edit/saveCloud)功能

- 本地导入的过滤无法随过滤作者的小版本更新而更新,需要再次重新编辑

## 使用方法

点击主页的本地导入按钮,选择过滤文件夹的 <mark>一乐过滤文件</mark> 导入即可,如图所示
