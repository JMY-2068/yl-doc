::: tip 温馨提示
使用云过滤无需下载过滤文件,在游戏过滤列表中显示 <mark>蓝色字体</mark> 的过滤就是云过滤
:::

## 直接关注别人上传的云过滤

官网上的入口藏得比较深,直接点击这个[官方云过滤列表](https://poe.game.qq.com/item-filter/ladder/follower),就可以看到所有玩家上传的云过滤了,选择自己需要的过滤,点击 <mark>关注</mark> 后,在游戏里使用即可,如下图所示

![云过滤列表](/assets/base/云过滤列表.png)

![关注云过滤](/assets/base/关注云过滤.png)

## 自己上传云过滤

### 第一步

在游戏官网登录自己的账号,点击 <mark>物品过滤</mark> 选项,如图所示

![点击物品过滤](/assets/base/点击物品过滤.png)
### 第二步

点击 <mark>新建过滤器</mark> 后,填写对应的过滤名称,描述,是否公开等信息,点击 <mark>提交</mark> 后即可,如下图所示

![提交过滤](/assets/base/提交过滤.png)

![我的云过滤列表](/assets/base/我的云过滤列表.png)

### 第三步

进入游戏,在过滤列表中选择刚刚创建的过滤,显示 <mark>蓝色字体</mark> 选择即可,如下图所示

![选择云过滤](/assets/base/选择云过滤.png)

::: tip 注意!!!
正常情况下,云过滤默认只支持系统音效,如果你下载的过滤是自定义音效的话,请注意仍要将压缩包里的 <mark>音效文件夹</mark> 放到 [本地过滤使用#第三步](/base/client#第三步) 章节中的 <mark>过滤文件夹</mark>中, 否则会提示报错 `无效的声音路径`
:::
