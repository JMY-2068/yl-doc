# POE Filter Best — 本地过滤文件编辑增强扩展

**POE Filter Best** 是一款专为 Path of Exile 过滤器文件（`.filter`）设计的 VSCode 扩展，提供语法高亮、智能补全、格式化、实时校验、颜色预览、效果预览、Block 管理面板等丰富功能，让编写过滤器就像写代码一样高效。

支持 **POE1** 和 **POE2（流放之路 降临）** 全部过滤器语法。

## 安装

在 VSCode 扩展市场搜索 **POE Filter Best** 安装，或手动安装 `.vsix` 文件。

安装后打开任意 `.filter` 文件即可自动激活。

## 语法高亮

7 种颜色区分不同语法类型，一目了然：

- 🟢 过滤块（Show / Hide）
- 🔵 是否类（Corrupted、Identified 等）
- 🟡 多选类（Rarity、HasInfluence 等）
- 🔢 数值类（ItemLevel、MapTier 等）
- 📋 数组类（Class、BaseType 等）
- 📝 词缀类（HasExplicitMod 等）
- 🎨 外观类（SetTextColor、MinimapIcon 等）

## 智能补全

输入即提示，上下文感知：

- `Show`/`Hide` 块头自动补全
- 所有条件关键字按分类排序提示
- 布尔值 `True`/`False`、颜色值、形状自动补全
- `Class` 支持 88 个物品类别（POE1 + POE2）

- 未知关键字、关键字不在 block 内、重复定义
- 参数类型错误、缺少必要参数

## 代码片段

15 个常用模板，输入前缀快速插入：

| 前缀 | 说明 |
|------|------|
| `currency` | 通货高亮 block |
| `unique` | 传奇物品 block |
| `map` | 地图过滤 block |
| `divcard` | 命运卡 block |
| `6link` | 6 连物品 block |
| `color-gold` / `red` / `green` / `blue` | 配色预设 |

## 格式化

`Shift+Alt+F` 一键格式化：统一缩进、规范空格、整理注释、合并空行。

## 代码折叠

每个 `Show`/`Hide` block 可折叠收起，连续注释块也可折叠。

`SetTextColor`/`SetBackgroundColor`/`SetBorderColor` 行显示内联颜色方块，点击可打开颜色选择器直接编辑 RGB 值。

## 定义跳转与引用

- **F12**：block 内任意行跳转到 Show/Hide 头行
- **Shift+F12**：查找所有同关键字行、同字符串值引用

## Block 状态切换

每个 block 上方显示可点击的 CodeLens 按钮，快速切换 4 种状态：

| 状态 | 效果 |
|------|------|
| 👁 显示(自定义) | Show + CustomAlertSound 生效 |
| 👁 显示(系统) | Show + PlayAlertSound 生效 |
| ⊘ 隐藏 | Hide + 视觉效果注释 |
| 🚫 禁用 | 整块注释 |

快捷键：`Ctrl+B Ctrl+T` 循环切换，`Ctrl+B Ctrl+S/Y/H/D` 直接切换。

## 快捷键

| 操作 | 说明 |
|------|------|
| `Shift+Alt+F` | 格式化文档 |
| `F12` | 跳转到 block 头行 |
| `Shift+F12` | 查找所有引用 |
| `Ctrl+B Ctrl+T` | 循环切换 block 状态 |
| `Ctrl+B Ctrl+S` | 显示(自定义音效) |
| `Ctrl+B Ctrl+Y` | 显示(系统音效) |
| `Ctrl+B Ctrl+H` | 隐藏 block |
| `Ctrl+B Ctrl+D` | 禁用 block |

## 扩展设置

| 设置 | 默认值 | 说明 |
|------|--------|------|
| `poe-filter-best.sectionSeparator` | ` - ` | 大纲/面板中 inline 注释的层级分隔符 |
| `poe-filter-best.panelDensity` | `comfortable` | 面板行间距：`compact` / `normal` / `comfortable` |

## 支持的语法

支持 Path of Exile 1 & 2 全部过滤器语法，包括：

- **条件**：ItemLevel、Rarity、Class、BaseType、HasExplicitMod、Sockets 等
- **动作**：SetTextColor、MinimapIcon、PlayEffect、PlayAlertSound 等
- **POE2 专有**：IsVaalUnique、WaystoneTier、Uncut Skill Gems 等
