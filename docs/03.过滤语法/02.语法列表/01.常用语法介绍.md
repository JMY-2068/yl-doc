## 过滤块语法

### 1.`显示和隐藏`

> <Badge text="英文语法" type="warning" /> → <mark>Show</mark> 或 <mark>Hide</mark>

> <Badge text="语法解释" type="warning" /> → 最基础的语法，写于一段过滤块的开头,用于显示或隐过滤块,如下代码分别代表显示和隐藏匹配的物品

> <Badge text="示例代码" type="warning" />
``` zig 
Show # 显示卡兰德的墨镜
    BaseType "Mirror of Kalandra" 

Hide # 隐藏卡兰德的墨镜
    BaseType "Mirror of Kalandra" 
```

## 是否类语法

判断物品是否满足某个语法,一般只有是和否2个值

### 1.`是否包含基底词缀`

> <Badge text="英文语法" type="warning" /> → <mark>HasImplicitMod</mark>

> <Badge text="语法解释" type="warning" /> → 判断物品是否至少包含一个基底词缀

> <Badge text="可 选 值" type="warning" /> → <mark>True</mark> 或 <mark>False</mark>

> <Badge text="示例代码" type="warning" />
``` zig 
Show # 显示包有基底词缀的物品
    HasImplicitMod True
```
