## 过滤块语法

### 1.`显示和隐藏`

> <Badge text="英文语法" type="warning" /> → <mark>Show</mark> 或 <mark>Hide</mark>

> <Badge text="语法解释" type="warning" /> → 最基础的语法，写于一段过滤块的开头,用于显示或隐过滤块,如下代码分别代表显示和隐藏匹配的物品

> <Badge text="示例代码" type="warning" />
``` zig 
Show # 显示卡兰德的墨镜
    BaseType "Mirror of Kalandra" 

Hide # 隐藏卡兰德的墨镜
    BaseType "Mirror of Kalandra" 
```

## 多选类语法

匹配满足指定条件中任意一个条件的语法

### 1.`稀有度`

> <Badge text="英文语法" type="warning" /> → <mark>Rarity</mark>

> <Badge text="语法解释" type="warning" /> → 设定匹配物品的稀有度

> <Badge text="可 选 值" type="warning" /> → <mark>Normal</mark> 和 <mark>Magic</mark> 和 <mark>Rare</mark> 和 <mark>Unique</mark>

> <Badge text="示例代码" type="warning" />
``` zig 
Show # 显示普通和魔法物品
    Rarity Normal Magic

Show # 显示普通和魔法和稀有物品
    Rarity Normal Magic Rare

Show # 显示传奇物品
    Rarity Unique
```

### 2.`具有何种势力`
> <Badge text="英文语法" type="warning" /> → <mark>HasInfluence</mark>

> <Badge text="语法解释" type="warning" /> → 设定匹配物品的影响势力

> <Badge text="可 选 值" type="warning" /> → <mark>Shaper</mark> 和 <mark>Elder</mark> 和 <mark>Crusader</mark> 和 <mark>Hunter</mark> 和 <mark>Redeemer</mark> 和 <mark>Warlord</mark>

> <Badge text="示例代码" type="warning" />
``` zig 
Show # 显示六势力影响物品
    HasInfluence Shaper Elder Crusader Hunter Redeemer Warlord
```

> <Badge text="特殊用法" type="warning" /> → 当加上<mark>==</mark>时，匹配双势力
``` zig 
Show # 匹配双势力塑界和裂界物品
    HasInfluence == Shaper Elder
```
