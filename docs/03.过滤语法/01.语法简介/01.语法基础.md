过滤语法是一种用于游戏内筛选物品的语法，你可以通过组合不同的过滤规则来筛选出符合要求的物品。你可以点击这个链接，查看[官方过滤语法解释](https://poe.game.qq.com/item-filter/about),当然官方介绍的比较简单,如果你想深入了解过滤语法的话,可以继续往下阅读

## 过滤文件

过滤文件本质上一个文本文件,文件名通常以`filter`结尾,将写好的过滤文件放置于过滤文件夹即可在游戏内选择并应用

## 过滤块

过滤文件由一个个 <mark>过滤块</mark> 组成,类似于以下代码

``` zig 
Show # 通货 - 基础通货* - 超高价值 - 卡兰德的魔镜
    Class "Stackable Currency" 
    BaseType "Mirror of Kalandra" 
    SetTextColor 255 255 255 
    SetBackgroundColor 255 40 0 230 
    SetBorderColor 255 40 0 0 
    SetFontSize 45
    MinimapIcon 0 Red Star 
    PlayEffect Red
#      PlayAlertSound 5 300 
    CustomAlertSound "音效\卡兰德的魔镜.mp3" 300
    DisableDropSound 

Show # 通货 - 基础通货* - 超高价值 - 辛格拉的发辫
    Class "Stackable Currency" 
    BaseType "Hinekora's Lock" 
    SetTextColor 255 255 255 
    SetBackgroundColor 255 40 0 230 
    SetBorderColor 255 40 0 0 
    SetFontSize 45
    MinimapIcon 0 Red Star 
    PlayEffect Red
#      PlayAlertSound 5 300 
    CustomAlertSound "音效\辛格拉的发辫.mp3" 300
    DisableDropSound 
```

包含2个过滤块,分别用于匹配 <mark>卡兰德的魔镜</mark> 和 <mark>辛格拉的发辫</mark> 这2个物品

## 过滤物品匹配机制
 
有2个基本机制
1. 从上往下匹配
2. 匹配到第一个符合条件的过滤块之后就停止往下匹配
